# Excel Converter — локальный прототип

Программа преобразует один лист Excel или CSV в заданную структуру, проверяет данные и сохраняет результат вместе с отчётом. Работает локально, не отправляет файлы в сеть. Исходные файлы не изменяются.

**Встроенный профиль демонстрационный. Образцы и спецификация системы департамента пока не получены; совместимость с ней не проверена.** Программа готовит данные, а не определяет правонарушения.

## Быстрый запуск на Windows

Если сборка уже создана, откройте `start.cmd` или `dist\ExcelConverter\ExcelConverter.exe`. Устанавливать Python и Excel для этой сборки не нужно. Для переноса на другой Windows-компьютер скопируйте **всю папку** `dist\ExcelConverter`, включая `_internal`, а не только EXE.

1. Нажмите **«Создать демо»** и выберите пустую папку. Программа создаст три учебных файла и откроет корректный пример.
2. Проверьте лист и строку заголовков. Для учебного Excel это **«Реестр», строка 3**.
3. На вкладке **«Сопоставление»** проверьте источники обязательных полей.
4. Нажмите **«Проверить и преобразовать»**. В корректном примере будут три записи.
5. На вкладке **«Проверки»** прочитайте предупреждения: служебные строки до заголовка и внутренний столбец не выгружаются.
6. Нажмите **«Сохранить результат»** и выберите новое имя. Рядом появится `имя.report.json` с проверками и происхождением строк.
7. Откройте `02_ошибки.xlsx`: неоднозначная дата, короткий идентификатор, формула и строка итогов заблокируют выгрузку. Отчёт об ошибках можно сохранить отдельно.

Третий пример — CSV с другим порядком и названиями столбцов; профиль определит их по синонимам.

## Возможности и правила

- Вход: `.xlsx` и CSV в UTF-8 (разделитель `;`, `,` или табуляция). Старый `.xls` нужно предварительно сохранить как `.xlsx`.
- Выход: `.xlsx`, один лист, точный порядок полей профиля. Выгружаются значения; оформление исходника, макросы, изображения и формулы не переносятся.
- Заголовки предлагаются по совпадениям в первых 30 строках. Номер строки и лист можно задать вручную. Дублирующиеся названия не сопоставляются автоматически.
- Даты: типизированная дата Excel, `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. Даты со временем, числовые серийные даты без типа даты и запись `01/02/2026` требуют исправления исходника.
- Суммы: максимум два десятичных знака, точка или запятая, группы тысяч через пробел. Неоднозначные разделители, лишняя точность и числа длиннее 15 цифр блокируются. Округление не выполняется.
- Идентификаторы: ровно 12 ASCII-цифр, выходной тип — текст. Ведущие нули сохраняются; утраченные нули не восстанавливаются. Это проверка формы, **не проверка существования БИН/ИИН или контрольного разряда**.
- Текстовые поля требуют текста. Например, числовой номер документа нужно проверить и сохранить как текст, чтобы не потерять ведущие нули.
- Валюта: три латинские буквы, преобразуемые в верхний регистр. Справочник допустимых кодов пока не подключён.
- Внешние пробелы в текстовых значениях удаляются. Назначение, начинающееся с `=`, сохраняется как буквальный текст, если исходная ячейка была текстовой.
- Формулы и ошибки Excel в выбранных полях блокируют выгрузку; формулы не исполняются и их кешированные результаты не используются.
- Пустые строки пропускаются и перечисляются в отчёте. Строки итогов автоматически не удаляются: их нужно отделить от таблицы в рабочей копии файла.
- Полные дубликаты преобразованных записей сохраняются с предупреждением. Столбцы без сопоставления и другие листы не попадают в результат; программа предупреждает об этом.
- Любая ошибка блокирует **весь** выходной файл; частичной выгрузки нет. Изменение листа, заголовков или сопоставления сбрасывает предыдущую проверку.
- Существующие результаты, отчёты и профили не перезаписываются. Выберите новое имя.

Предпросмотр показывает первые 200 строк, список проверок — первые 2000 замечаний. Преобразование и JSON-отчёт охватывают все прочитанные записи. Лимит прототипа — 100 000 строк и 256 столбцов на лист; весь файл читается в память. Производительность на больших рабочих файлах ещё не измерялась. Пакетная обработка папки пока не включена.

## Профили

Встроенный профиль: `excel_converter/profiles/demo.json`. Кнопка **«Сохранить профиль»** сохраняет структуру и текущее сопоставление по точным названиям исходных столбцов. Для повторного использования нажмите **«Загрузить профиль»**. Для разных вариантов исходников сохраняйте отдельные профили. Выбранные заголовки должны быть непустыми и уникальными.

Для изменения целевого формата скопируйте JSON-профиль и измените:

- `name`, `description` — название и описание;
- `sheet_name` — название выходного листа;
- `fields` — поля в выходном порядке: `id`, `title`, `kind`, `required`, `aliases`;
- `kind` — `text`, `date`, `identifier`, `amount` или `currency`;
- `mapping` — необязательное сопоставление идентификатора поля с точным названием исходного столбца; `null` означает «не выбрано».

Для автоматического распознавания нового варианта исходника очистите `mapping` до `{}` и задайте `aliases`. Сохранённое явное сопоставление имеет приоритет над синонимами.

Константы, вычисляемые поля, несколько целевых листов, объединение таблиц, специальные справочники и правила удаления итогов добавляются после получения спецификации. Пока редактор структуры профиля — обычный текстовый редактор; в интерфейсе редактируется сопоставление.

## Отчёт обработки

JSON содержит версию приложения, время UTC, имя и SHA-256 исходного файла, выбранный лист, заголовок, полный профиль, индексы сопоставления, число записей, ошибки, предупреждения, пропущенные пустые строки и связь выходной строки с исходной. После выгрузки добавляются имя и SHA-256 результата. Номера строк — как в Excel, с единицы; индексы столбцов в `mapping_indices_zero_based` — с нуля.

Отчёт обеспечивает прослеживаемость конвертации, но не является журналом с защитой от изменения. Он не подтверждает полноту исходных сведений или достоверность операций. Контрольные суммы финансовых показателей следует согласовать по валютам и правилам департамента; общий итог по разным валютам программа не складывает.

## Запуск из исходников

Нужен Python 3.11+ с Tkinter. В PowerShell из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m excel_converter
```

После установки можно использовать `start.cmd`. Если папка готовой сборки существует, этот файл запускает её в первую очередь.

Командная строка:

```powershell
.\.venv\Scripts\python.exe -m excel_converter demo demo
.\.venv\Scripts\python.exe -m excel_converter convert demo\01_корректный.xlsx converted.xlsx --header 3 --accept-warnings
.\.venv\Scripts\python.exe -m excel_converter convert demo\02_ошибки.xlsx blocked.xlsx --header 3 --report validation.json
```

Дополнительные параметры: `--sheet "Реестр"`, `--profile custom_profile.json`. При нескольких листах CLI требует `--sheet`. Коды завершения: `0` — успех, `1` — ошибка чтения/настроек/сохранения, `2` — ошибки данных, `3` — предупреждения требуют `--accept-warnings`. Используйте последний параметр после просмотра замечаний.

## Проверки и сборка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
$env:PYTHONPATH = (Get-Location).Path
.\.venv\Scripts\python.exe tests\gui_smoke.py
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\build.ps1
```

Автотесты проверяют чтение Excel/CSV, эталонный результат, типы ячеек, сохранение нулей, строгие даты/суммы, формулы, неоднозначные заголовки, профили, дубликаты, отчёт, запрет перезаписи и CLI. Проверка интерфейса дополнительно покрывает загрузку, сопоставление, предпросмотр, сброс проверки после изменений и блокировку сохранения.

## Что получить от департамента для следующего этапа

1. Несколько обезличенных исходников и соответствующих результатов ручной обработки.
2. Пустой выходной шаблон и описание обязательных типов/форматов.
3. Правила по итогам, пустым строкам, возвратам, дубликатам, валютам и формульным ячейкам.
4. Ограничения рабочих компьютеров и реальные размеры файлов.
5. Возможность пробной загрузки результата в их систему и критерии приёмки.

Затем настроить профиль, добавить необходимые правила, сравнить результат с ручным эталоном и проверить фактическую загрузку в систему.
